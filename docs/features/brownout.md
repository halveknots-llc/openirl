# Brownout Engine

Exporter or status-line contributions should use the
[metrics parser recipe](../contributing/metrics-parser.md) so fixtures, bounded
ingestion, reducer semantics, and live evidence stay separate.

This feature area is represented by Rust types, API surfaces, presets, docs, and smoke-test paths in the alpha source package. Runtime validation should be performed on a machine with OBS, MediaMTX, and the relevant encoder or relay tools installed.
